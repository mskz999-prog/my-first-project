# カルーセル制作の手順（本人用）

Claude Code に話しかける言葉と、自分で手を動かす作業だけを書いています。
裏側では3つのスキル（vfn-plan → vfn-assets → vfn-publish）が順番に動きます。

| # | 工程 | あなたがやること | Claudeがやること |
|---|---|---|---|
| 1 | 企画 | 「**○○のカルーセル作りたい**」と伝える。参考URLや手描きチャートがあれば一緒に貼る | リサーチして、実物写真もざっと見たうえで、年代ごとのディテール表を出す |
| 2 | 下書き | 表を見て「**下書きして**」 | 下書きを作る → ファクトチェック担当（サブエージェント）が独立に裏取り → 直した点を報告 |
| 3 | 構成OK | 構成・文言を確認して直したい点を伝える | 修正 |
| 4 | 参考写真 | 「**画像集めて**」。気になる出品URLがあれば貼る | メルカリ・ヤフオク・ブログから**オリジナルだけ**を集め、見どころに寄せて切り抜き・点検して、出典付きの非公開プレビューを見せる |
| 5 | 写真の差し替え | 「この写真は暗い」など気になる点を伝える | 差し替え |
| 6 | Geminiプロンプト | 「**geminiのプロンプトちょうだい**」 | 番号付きのプロンプト集と添付ファイルを1つのフォルダにまとめて開く |
| 7 | Gemini生成 | **番号ごとにGeminiの新しいチャット**を開き、「添付」欄のファイルを**書いてある順番どおり**に付けてプロンプトを貼る。できた画像を、**番号を書いて**Claudeのチャットに貼る（例：「05」＋画像。何枚まとめてでもOK） | 保存・組み込み → 文字や刻印が正しいか確認 → ページを作り直して見せる。崩れていたら修正プロンプトを出す |
| 8 | 最終版 | 全部そろったら「**最終チェックして**」 | 公開版を作る → 最終チェック担当（サブエージェント）が全ページ点検 → 全ページ見せる |
| 9 | コミット | 「**コミットして**」→ GitHub Desktop で **Push origin** | コミット |
| 10 | 投稿準備 | 「**写真に保存して、キャプションとハッシュタグちょうだい**」 | 写真アプリのアルバム「VFN ○○」に投稿順で保存、キャプションとハッシュタグを出す |
| 11 | 投稿 | スマホの写真アプリにアルバムが同期されたら、Instagramで順番どおりに選んでキャプションを貼って投稿 | — |

## Geminiのコツ（557・507XXで分かったこと）
- **細部の絵は「写真1枚だけ添付して、そのまま水彩にする」のが一番崩れない**（507XXで確立。プロンプトは自動でこの形になる）。
  そのぶん参考写真の出来がそのまま絵に出るので、写真選びと切り抜きはClaudeが先に念入りにやる。
- 色はプロンプトで「写真どおり・薄くしない」と指定している。それでも薄く出たら「Make the colors exactly as dark and saturated as the photo」と同じチャットで頼む。
- **番号ごとに新しいチャット**で始める（前の絵に引っ張られる）。余計な物が足されたら、同じチャットで直すより新しいチャットの方が早い。
- 表紙は「形が写らない画風見本（VANSの靴の絵）＋実物写真2〜3枚」。別モデルの服の絵を見本にすると形まで真似される。
- 一度できた絵の「パーツを動かす」修正（例：袖と胴の隙間）はほぼ直らない。置き方は最初のプロンプトと写真で決める。
- 2つの年代で見た目が同じ項目は、同じ絵の使い回しでOK。
- 文字や刻印は崩れやすい。Claudeが拡大して確認するので、気になる点はそのまま伝えればOK。

## 困ったとき
- 「今どこまで進んでる？」と聞けば、画像の済／未の一覧を出します。
- Gemini画像は `content_studio/gemini_inbox/` に「05.png」のような名前で置いてもOK（「inboxから取り込んで」と言う）。
